# 契约之刻 · 你最可能召唤哪位英灵

一个移动端优先、可离线使用的 Fate 非官方同人测评网页。32 次选择分为四章：远行之前、军旗之下、灯火归途、星海与圣杯。完成后，揭晓回应召唤的英灵，阅读能回看答案依据的个人解读、角色档案与历史原型，并保存召唤档案图片。

## 直接体验

网站地址：[契约之刻](https://cdsgd.github.io/fate-summoning/)。手机直接用浏览器打开即可，无需下载项目文件。

也可以双击本目录中的 `index.html` 离线使用，无需安装软件或运行服务器。页面的字体、图片和脚本无需外部加载；档案中的资料来源链接需要网络。姓名、答案和进度仅保存在当前浏览器。

## 题库与体验

- 32 道原创题，四章各 8 题。包含 3 道爱情与亲密关系题、7 道历史战争题、8 道行为偏好题、2 道七档态度量表，以及 3 道可略过的故事审美题。
- 战争题采用当事人视角，逐题交代你的身份、处境和决定范围。故事灵感来自历史、神话、传说或文学，题面不提前点出英灵姓名。
- 八道行为题围绕恢复精力、接收信息、决定依据、安排节奏四个方面展开，每个方面两题。参考 MBTI 常见的偏好主题设计原创场景，不直接询问类型，也不输出四字母人格类型或诊断。
- 最后一道圣杯题提供七种具体优先项：个人财富、健康与时间、顶尖技艺、公开认可、亲近者的健康、公共生活改善、暂时保留愿望。每项说明能获得什么；财富、救治等选项之间保留明确的边界与机会成本。
- 选中答案后留在当前题，点击“继续”才前进；末题同样需要确认。支持返回改选、刷新恢复进度、数字键选择，以及聚焦“继续”后按 Enter 确认。
- 24 位 Fate 英灵、次级共鸣结果、六维雷达图、可逐项回看的结果依据，以及按职阶和原型分类检索的英灵档案。
- 召唤结果直接展开游戏内人物简介和一则著名故事；图鉴同步收录。历史、神话、传说、文学与作品原创故事分别标注，附进一步阅读来源。
- 首页、答题、结果与资料链接使用简洁文字按钮，去掉装饰性箭头。
- 姓名或昵称生成固定的中文、英语、日语或法语原创御主代号，贯穿答题、结果和 PNG；姓名与代号不影响匹配。
- FGO 初始灵基卡面、首页七职阶预览、职阶卡翻面与真名揭晓；原创 SVG 召唤阵、令咒、触媒和可选合成音效。
- 导出 1080×1920 PNG 召唤档案，手机显示真实图片预览，可下载或长按保存；支持文件分享的浏览器可调用系统分享。适配窄屏、键盘访问和减少动态效果偏好。

## 评分与解释

六维取舍题只对选项明确涉及的愿景、谋略、联结、表达、规则、行动计分；未提供线索的维度记为零。两道态度量表使用七档认同程度，中心回答参与计分。三道故事审美题只作偏好回顾，选择或略过均不影响六维、行为偏好与英灵匹配。

六维匹配先扣除各题选项的平均分，再用同一题库的加权协方差校正维度相关性，比较回答方向与英灵画像方向。双方均使用单位向量，画像距离中心较近不会自动占优；不设置人物配额、随机补位或某一角色的独立加权。

v12 按体验偏好，让所有五星英灵统一获得 `0.03` 相似度的召唤排序加分，只影响接近的候选。其他英灵的原始相似度领先超过 `0.03` 时仍会保留；共鸣指数根据被召唤英灵未经星级加分的答案相似度计算，星级不会虚增人格共鸣。固定 50,000 组独立随机回答中，五星合计从 49.706% 增至 58.030%，全部 24 位仍可匹配。这是合成压力测试结果，不是实际玩家概率。

行为偏好独立于六维。每个方面至少需要两题同向，才概括其偏好并让这个方面参与匹配；答案相反时保留分歧。行为部分在六维与行为的合成中最高占 25%，证据不足时按有效方面减少权重。圣杯愿望另占最终相似度的 10%，其余 90% 来自前述合成；愿望只表示这次想优先改变什么，不据此推出善恶、能力或整个人格。英灵的行为画像与愿望侧面均为本项目的同人解读。

结果解释从实际回答生成。价值倾向和共鸣概括需要至少两道题的支持，并提供原题与选择的回看入口；出现反向答案时注明反例。回答混合或证据不足时，允许保留不同取舍、减少结论，不凑满固定数量的赞美理由。结果另列与英灵的差异和单题愿望回顾。

共鸣指数表示本测试的相对适配程度，不代表 Fate 游戏的真实召唤概率、官方参数或心理测量结论。接近并列时提示其他英灵；六维线索较弱时，页面和 PNG 都会说明此次回应只是一种可能。相同答案得到相同结果，改名不改变排名。

v11 使用新的浏览器保存键 `fate-summoning-contract-v11`。本轮题目数量与选项含义已有变化，旧版答题记录不会自动转换成新版答案。

v12 题库不变，继续使用该保存键；已保存的 32 题答案会按当前匹配模型重新计算结果。

## 修改与发布

主要文件：

- `questions-v11.json`：32 道题、选项、明确测量的维度、行为偏好和故事来源。
- `data.js`：章节、英灵、原型、来源和总匹配流程；`matching.js`：六维方向校正。
- `behavior.js`：独立行为分析与英灵行为画像；`wish-priorities.js`：单题愿望与英灵侧面的对应。
- `explanations.js`：共鸣、差异与证据边界；`reading.js`：实际答案的个人解读。
- `servant-lore.js`：全 24 位英灵的游戏内简介、著名故事、分类与资料来源。
- `app.js`：交互、进度、档案与 PNG；`master-code.js`：确定性四语御主代号。
- `art.js` / `fate-art.js`：原创 SVG 和音效；`portraits.js` / `assets/portraits`：带来源的角色卡面，`sources.json` 保留素材元数据。
- `style.css` / `game.css` / `motion.css`：排版、从者界面和切题动效；`index.template.html`：页面框架。
- `build.py`：把源码、题库和资源生成到单文件 `index.html`。

修改后在本目录运行 `python build.py`，检查生成页面，再提交并推送。本仓库通过 GitHub Pages 托管：推送到 `main` 后，`.github/workflows/pages.yml` 会重新构建并自动发布，部署记录见仓库的 Actions。首次配置时，在 Settings → Pages → Build and deployment 选择 GitHub Actions。也可以将生成的 `index.html` 放到其他静态网站托管服务。

## 内容与来源

测评场景、选项、匹配文案和召唤寄语为原创；寄语不作为角色原台词引用。题型组织参考了 D&D 阵营测试中的承诺与利益冲突，以及分院测试和《宝可梦不可思议迷宫》用具体场景区分选择的方法，未照搬题库、答案或官方评分。本作不是这些测试的联合认证或心理学量表。

- [D&D Alignment Test](https://easydamus.com/alignmenttest.html)
- [Wizardmore Extended Sorting Hat Quiz（非官方整理）](https://wizardmore.com/sorting-hat-x/)
- [Bulbapedia · Personality Quiz (Mystery Dungeon)](https://bulbapedia.bulbagarden.net/wiki/Personality_Quiz_(Mystery_Dungeon))

人物档案区分历史、神话、传说、文学与原创人物，并附资料来源。Fate 改编的性别、职阶、宝具与剧情不能据此推断历史；有争议的作者、年代与身份保留不确定性。战争题在 `inspiration` 中记录对应人物、故事类型与来源；题目选择和后果为原创推演，不声称人物实际作出了这些决定。

FGO 初始稀有度、宝具、技能和指令卡颜色按选定展示版本记录，版本和来源见角色的 `game.version`、`game.sourceUrl`。这些游戏资料与测评自设分数分开展示。御主代号是基于姓名生成的原创称号，不是姓名翻译或真实语源。

Fate 及角色相关权利归各权利方所有。本项目与 TYPE-MOON、Aniplex 等官方无关联。角色卡面为 FGO 游戏素材，经 Atlas Academy 公开资源整理，页面和素材清单保留出处，不宣称立绘为本项目原创。召唤阵、令咒图形、职阶卡背、触媒线稿与短音效为本项目原创。

## 本地检查

先运行 `python build.py`。当前 v12 检查命令：

```sh
node qa_v12.mjs --samples 50000
python qa_v11_browser.py
python qa_v11_layout.py
python qa_v12_browser.py
```

逻辑审计直接调用生产评分，检查题库边界、行为双题门槛与冲突处理、共鸣和差异的真实答案依据、愿望的独立贡献、全部 80 种审美组合不影响匹配，以及 24 位英灵的可重放答案见证。固定种子随机回答用于压力测试，不能当作真实玩家概率或结果应均分的依据。

三份浏览器检查需使用仅供本项目测试、在 `127.0.0.1:9333` 监听的隔离 Chrome DevTools 实例，依次运行。前两份沿用题库版本的文件名，检查当前模型。完整流程覆盖 32 题身份与确认、键盘操作、保存恢复、答案回看、召唤与 PNG 实际下载；布局检查覆盖 320px、390px 窄屏、战争题、七档量表、长代号与 PNG；新增界面检查核对继续测试按钮、各界面箭头、直接展开的双简介及全部 24 位图鉴资料。浏览器仿真不能代替实体手机的原生相册菜单验收。

本轮 v12 验证（2026-11-18）：逻辑审计 73,109 项通过，50,000 组答案覆盖 24/24 位英灵；原相似度差距超过 0.03 的 35,478 个明确领先结果全部保留。浏览器流程 260 项、窄屏布局 61 项、新增界面与 24 位图鉴检查 20 项全部通过，无运行异常。报告为 `qa/report-logic-v12.json`；界面报告分别为 `qa/report-flow-v12.json`、`qa/report-layout-v12.json`、`qa/report-ui-v12.json`，记录对应源码或构建哈希。截图、导出图片与报告仅保留在本地 `qa/`，不提交到 GitHub，可用以上脚本重新生成。旧版脚本与报告保留作历史记录。
