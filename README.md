# 契约之刻 · 你最可能召唤哪位英灵

一个移动端优先、可离线使用的 Fate 非官方同人测评网页。二十四次选择分为四章：远行前的牵挂、军旗下的抉择、归来后的关系，以及星海与圣杯前的愿望。完成后，揭晓回应召唤的英灵，阅读有答案依据的个人解读、角色档案与历史原型，并保存自己的召唤档案图片。

## 直接体验

双击本目录中的 **`index.html`** 即可在现代浏览器中打开，无需安装软件或运行服务器。也可以将它放入任意静态网站托管服务，以 `index.html` 为首页。

页面无外部字体、图片、脚本依赖。姓名、答案和进度仅保存在当前浏览器。档案中的资料来源链接需要网络。

## 在线访问与更新

网站地址：<https://cdsgd.github.io/fate-summoning/>。

本仓库通过 GitHub Pages 托管。每次推送到 `main`，`.github/workflows/pages.yml` 会重新生成网页并自动发布；部署记录可在仓库的 **Actions** 中查看。手机用户直接用浏览器打开网站地址即可，无需下载项目文件。

修改题库、页面或样式后，在本目录运行 `python build.py`，检查 `index.html`，再提交并推送。首次配置时，在仓库 **Settings → Pages → Build and deployment** 中选择 **GitHub Actions**。项目可离线双击打开，也可以在其他静态托管服务上发布生成的 `index.html`。

`qa/` 中的浏览器截图和运行报告只保留在本地，不提交到 GitHub。仓库中的 QA 脚本可以重新生成报告。

## 已包含的功能

- 24道原创题，四章各6题、六维倾向匹配；最后一题是在圣杯前作出自己的愿望。
- 四章依次为“远行之前 / 远行前的你”“军旗之下 / 身在战局的你”“灯火归途 / 归来后的你”“星海与圣杯 / 圣杯前的御主”。章节保持同一叙事主题；战争题让你成为故事当事人，逐题说明处境与决定范围。量表直接呈现陈述与认同程度。
- 3道爱情与亲密关系题分布在第一、三章；7道历史战争题包括第二章的6次亲历抉择，以及第三章的一次战后选择。故事取材于英灵原型的历史、神话、传说或文学，题面不提前点出人物姓名。
- 选中答案后保留当前题，点击“继续”才前进；末题也需明确确认后才进入召唤。答题外壳常驻，题面局部过渡，可随时返回改选。
- 24 位 Fate 英灵，确定性匹配、次级共鸣结果、雷达图。
- 24位英灵的FGO初始灵基卡面，首页七职阶角色预览、职阶卡翻面与真名揭晓。
- 原创 SVG 召唤阵、三划令咒、触媒卡片和可选合成召唤音效。
- 普通题按情境提供2至5个实质选项；另有2道权重0.75的七档态度量表，以及3道权重0.4的历史审美题。量表中心是中立回答，仍参与该题计分；只有审美题提供不计分的略过选项，略过会同时排除该题的得分与归一化范围。
- 输入姓名或昵称时，实时预览固定的中文、英语、日语或法语原创御主代号；代号贯穿答题、结果与PNG档案。姓名与代号只用于身份呈现，不影响英灵得分。
- 有足够多题依据时，结果给出个人解读，每条由至少两次实际回答支持，可逐条回看原题与自己的选择；回答混合时保留不同处境下的取舍，不强行归为单一类型。另列与英灵的共鸣、差异与六维倾向，接近并列时说明匹配接近。宝具、指令卡颜色、初始稀有度与代表技能按FGO展示版本记录。
- 历史/神话/传说/文学/原创人物分类；每位角色均区分原型与 Fate 改编设定，附资料来源。
- 可搜索、按职阶与原型筛选的英灵档案。
- 返回改答案、刷新恢复进度；生成 1080×1920 PNG 召唤档案，含姓名、英灵卡面、职阶、共鸣理由、宝具和原型简介。
- 手机以真实图片预览，支持浏览器长按保存；提供独立 PNG 下载，在支持文件分享的浏览器中提供系统分享。
- 手机适配、键盘访问、减少动态效果偏好支持；数字键只选择答案，聚焦“继续”按钮后按 Enter 才确认前进。

## 修改内容

- `data.js`：题目、英灵、原型说明、来源、匹配逻辑。
- `art.js`：原创召唤阵、圣遗物徽记、职阶 SVG。
- `fate-art.js`：原创令咒、职阶卡背、触媒 SVG、Web Audio 音效。
- `portraits.js` / `assets/portraits`：带来源的离线角色卡面；`sources.json`保留素材元数据。
- `app.js`：交互、进度保存、档案、分享卡片。
- `master-code.js`：姓名规范化与确定性四语御主代号；不参与人格评分。
- `reading.js`：从实际答案的重复倾向生成个人解读与回看依据。
- `style.css`：颜色、字体、排版与动效。
- `game.css`：从者卡、御主界面、翻卡召唤与宝具资料的视觉样式。
- `motion.css`：常驻答题外壳、局部切题、页面过渡与手机题面高度衔接。
- `index.template.html`：页面框架。

修改后，在此目录执行 `python build.py`，重新生成单文件 `index.html`。

## 关于内容

测评与匹配文案属于原创同人解读。共鸣指数表示本测试的相对适配程度，不代表 Fate 游戏的真实召唤概率或官方能力参数。原创召唤寄语不作为角色原台词引用。

历史人物、神话人物与文学人物分开标注。角色的性别、职阶、宝具、人格和剧情采用 Fate 改编语境，不能据此推断历史。对于作者、年代与身份存在争议的传说，档案保留不确定性。可沿每位角色的资料链接继续阅读。

Fate 及角色相关权利归各权利方所有。本项目与 TYPE-MOON、Aniplex 等官方无关联。角色卡面为FGO游戏素材，经Atlas Academy公开资源整理，页面和素材清单保留出处；不宣称这些立绘为本项目原创。召唤阵、令咒图形、职阶卡背、触媒线稿和短召唤音效为本项目原创。

FGO初始稀有度、宝具和技能资料与适性测评的自设分数分开展示。具体采用的数据版本与来源记录在每位角色的`game.version`和`game.sourceUrl`，可沿链接核对。战争题中的故事灵感记录在`inspiration`，含对应人物、故事类型和来源；题目中的选择与后果均为原创推演，不声称人物实际作出了列出的决定。三道历史审美题仅补充你关注历史意象与故事的方式，不将某种审美偏好机械绑定某位角色。御主代号是基于姓名生成的原创称号，并非姓名翻译或真实语源；同一规范化姓名得到相同代号，修改姓名不会改变英灵匹配分数。

v9 题库使用新的浏览器保存键，以免将旧版选项的答案误用于改为当事人视角的题库。旧版数据不会自动转换成新答案。

题目场景、选项和匹配文案为本项目原创。虚构处境用于呈现不同选择的后果；引用书籍与历史背景时，将理解题目所需的信息写在题面里。人物档案的史料出处独立列示。

题型组织参考了 D&D 阵营测试中的承诺与利益冲突，以及分院测试和《宝可梦不可思议迷宫》性格测试中用具体场景区分选择的方法。当前题库将爱情、战争、行动倾向、审美与愿望分置于四章。未照搬题库、答案或官方评分；六维匹配、个人解读和英灵画像为本项目自设，不是这些测试的联合认证或心理学量表。

- Wizardmore Extended Sorting Hat Quiz（非官方整理）：<https://wizardmore.com/sorting-hat-x/>

## 本地检查

`qa_v8.py`（也可通过`qa_browser.py`）从实际题库动态读取题数、题型与选项数，检查选中后等待至少800毫秒仍停留当前题、点击“继续”才前进、数字键仅选择、题面 Enter 不前进、聚焦“继续”后的 Enter 确认，以及末题确认、返回修改和刷新恢复。

当前脚本沿用`qa_v8.py`文件名，验证v9题库：四章各6题、3道爱情题与7道历史战争题的章节分布、当事人身份随当前题更新、战争题来源映射、2道七档量表及其键盘操作、3道可略过审美题、最后的圣杯愿望，以及结果个人解读的真实答案与逐项回看。姓名四语代号仍核对实时预览、刷新恢复、结果一致和PNG实际绘制；导出会在浏览器中执行真实下载并核对文件内容。当前完整报告为`qa/report-v9.json`，截图带`-v9.png`后缀，旧版报告与截图保留。

`qa_v8_layout.py`另检查320px、390px宽度下的四语代号、7道历史战争题的当事人身份与题面、动态定位的两道量表、个人解读及法语长代号PNG。两套检查都要求一个仅供本项目使用、在9333端口监听的Chrome DevTools实例；运行命令为`python qa_v8.py`和`python qa_v8_layout.py`。浏览器仿真不能代替具体手机浏览器的原生相册菜单验收。
